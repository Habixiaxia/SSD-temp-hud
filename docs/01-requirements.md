| 项目 | 内容 |
|---|---|
| 产品名称 | 盘温（内部代号 SsdTempHud） |
| 文档版本 | v0.1 |
| 日期 | 2026-10-19 |

| 目标平台 | Windows 10 2004+ / Windows 11，x64 |
| 使用对象 | 仅本人（单机、无账号体系） |

---

## 1. 背景与目标

在玩游戏时，SSD 持续高负载发热，但玩家无法看到硬盘温度，存在过热降速甚至损坏的隐患。系统自带任务管理器只能看到磁盘活动率，看不到温度；HWiNFO 等工具信息过载且不适合游戏场景。

**目标**：做一个常驻的、贴在屏幕顶部的极简横条，在游戏中也能一眼看到每块内置硬盘的**实时温度**与**磁盘活动率**，同时尽量不干扰游戏。

**成功标准**：进游戏前打开它，一局游戏结束后我能回答"刚才哪块盘最热、有没有超过警戒线"，且全程不需要切出游戏。

## 2. 用户故事

| 编号 | 用户故事 |
|---|---|
| US-01 | 作为玩家，我在无边框窗口模式下游戏时，仍能看到所有内置硬盘的当前温度。 |
| US-02 | 作为用户，我能看到每块盘的实时磁盘活动率，判断是否在大量读写。 |
| US-03 | 作为玩家，悬浮条不抢焦点、不挡鼠标操作，我可以一键让它"穿透"或隐藏。 |
| US-04 | 作为用户，温度过高时我能立刻通过颜色变化注意到。 |
| US-05 | 作为用户，我不想每次开机手动打开它，希望它能开机自启。 |

## 3. 范围

### 3.1 本期范围（v1.0）

- 枚举**内置**物理磁盘：主板自带的 NVMe / SATA 硬盘，以及用户自行加装的 SSD / HDD。
- 读取并显示每块盘的：型号简称、盘符、**温度（°C）**、**磁盘活动率（%）**。
- 屏幕顶部固定横条，置顶、半透明、无边框、不占任务栏。
- 温度分级配色（正常 / 偏高 / 危险）。
- 鼠标点击穿透模式；托盘图标菜单；全局热键显示/隐藏。
- 配置持久化（位置、透明度、刷新间隔、阈值、自启）。
- 开机自启；单实例运行。

### 3.2 本期不做（Non-goals）

- CPU / GPU / 主板温度、风扇转速。
- 温度历史曲线、日志导出、邮件/推送告警。
- 远程查看、手机端、多机集中监控。
- 跨平台（macOS / Linux）。
- 外接 USB 硬盘盒、U 盘、网络盘、RAID 虚拟盘（温度通常不可读）。
- 注入游戏进程或使用内核驱动实现独占全屏覆盖。

## 4. 功能需求

| 编号 | 需求 | 说明与验收要点 | 优先级 |
|---|---|---|---|
| FR-01 | 磁盘枚举 | 列出所有内置物理磁盘，显示型号简称与盘符；无法识别型号时显示 `Disk N`。 | P0 |
| FR-02 | 温度采集 | NVMe 走 Windows Storage 温度查询；SATA 走 SMART 属性；单块盘读取失败显示 `--`，不得崩溃或卡死。 | P0 |
| FR-03 | 活动率采集 | 每秒采样一次磁盘繁忙百分比（0–100%），与任务管理器趋势一致。 | P0 |
| FR-04 | 顶部悬浮横条 | 无边框、始终置顶、不显示在任务栏、不抢焦点；默认贴屏幕顶部居中，高度约 32–36 px。 | P0 |
| FR-05 | 温度配色 | 默认 <65°C 正常（青绿）、65–74°C 偏高（琥珀）、≥75°C 危险（红色）；阈值可配置（依据实机待机温度 51–58°C 调整）。 | P0 |
| FR-06 | 点击穿透 | 默认开启，鼠标事件穿透到下层窗口；可从托盘菜单或热键临时关闭以进行操作。 | P0 |
| FR-07 | 托盘菜单 | 显示/隐藏、穿透开关、暂停刷新、开机自启、退出。 | P0 |
| FR-08 | 全局热键 | `Ctrl+Alt+H` 显示/隐藏横条；`Ctrl+Alt+M` 切换穿透模式。 | P1 |
| FR-09 | 配置持久化 | 保存到 `%APPDATA%\SsdTempHud\config.json`；损坏时回退默认值并备份原文件。 | P0 |
| FR-10 | 开机自启 | 通过计划任务以最高权限在登录时启动，避免每次弹 UAC（可开关）。 | P1 |
| FR-11 | 单实例 | 重复启动时激活已有实例并退出新进程。 | P1 |
| FR-12 | 多显示器 | 可选择显示在哪个显示器的顶部；默认主显示器。 | P1 |
| FR-13 | 异常自愈 | 单次采集超时/异常不影响其他磁盘与界面；连续失败时降级为 `--` 并在托盘提示。 | P0 |
| FR-14 | 退出清理 | 退出后进程、托盘图标、热键注册全部释放。 | P0 |

## 5. 非功能需求

| 编号 | 类别 | 指标 |
|---|---|---|
| NFR-01 | 启动性能 | 从双击到横条显示数据 ≤ 3 秒。 |
| NFR-02 | 资源占用 | 空闲时 CPU ≤ 0.5%（单核）、内存 ≤ 80 MB；不随运行时长持续增长。 |
| NFR-03 | 游戏影响 | 无动画、无高频重绘；不引发游戏掉帧或卡顿。 |
| NFR-04 | 稳定性 | 连续运行 8 小时无崩溃、无句柄/内存泄漏；界面线程不因采集阻塞。 |
| NFR-05 | 权限 | 以管理员权限运行（读取 SMART 的必要条件），启动时通过清单请求提权。 |
| NFR-06 | 安全 | 只读访问磁盘；不加载第三方内核驱动；不联网；不上传任何数据。 |
| NFR-07 | 兼容性 | Windows 10 2004+ / Windows 11 x64；DPI 100%–200%；中英文系统均可用。 |
| NFR-08 | 可维护性 | 采集层与界面层解耦；新增传感器类型不改动 UI 代码；关键错误写本地日志（滚动、上限 1 MB）。 |

## 6. 界面约定（顶部横条）

```
┌──────────────────────────────────────────────────────────────────────┐
│  C:  NVMe  45°C  ███░░  12%     E:  SATA  38°C  █░░░░   3%         │
└──────────────────────────────────────────────────────────────────────┘
```

- 深色半透明背景（默认不透明度 85%），圆角，细边框，白色文字。
- 每块盘一个信息块：`盘符 + 类型 + 温度 + 活动率条形图 + 百分比`。
- 温度达到阈值时，对应数字与条形图变为琥珀/红色。
- 横条宽度随磁盘数量自适应，超出屏幕时横向滚动或换行（v1 先做自适应缩放）。
- 鼠标悬停（穿透关闭时）显示完整型号与"点击穿透已关闭"提示。

## 7. 约束与已知风险

| 编号 | 风险 | 影响 | 应对 |
|---|---|---|---|
| R-01 | 读取温度必须管理员权限 | 每次启动弹 UAC | 提供计划任务自启方案；文档说明。 |
| R-02 | **独占全屏（Exclusive Fullscreen）会遮盖普通置顶窗口** | 该模式下可能看不到横条 | 明确告知建议使用"无边框窗口/窗口化全屏"；v1 不承诺独占全屏可见。 |
| R-03 | 部分 SATA 盘无 SMART 194 属性，或厂商语义不同 | 温度显示 `--` 或偏差 | 依次尝试 194 / 190 / 厂商扩展；失败降级显示。 |
| R-04 | NVMe 温度可能是 Composite 或多传感器 | 读数与厂商工具略有差异 | 优先 Composite；文档注明误差范围。 |
| R-05 | 反作弊软件对覆盖层/驱动敏感 | 极端情况下被误判 | 不注入、不装驱动、不读写游戏内存；仍建议用户自行评估。 |
| R-06 | 磁盘性能计数器实例名随系统语言/拓扑变化 | 活动率匹配错误 | 以物理磁盘序号绑定；必要时回退 `IOCTL_DISK_PERFORMANCE`。 |
| R-07 | 不同 DPI 显示器间坐标换算 | 横条错位 | 进程声明 Per-Monitor V2 DPI 感知。 |

## 8. 验收标准

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| AC-01 | 启动出数 | 管理员运行后 3 秒内，横条列出本机全部内置磁盘及温度、活动率。 |
| AC-02 | 温度准确性 | 与 CrystalDiskInfo / HWiNFO 对比，误差 ≤ 2°C。 |
| AC-03 | 活动率一致性 | 与任务管理器"性能 → 磁盘"趋势一致，偏差 ≤ 10%。 |
| AC-04 | 游戏内可见 | 无边框窗口模式下运行游戏，横条持续可见、不抢焦点、鼠标可穿透。 |
| AC-05 | 异常降级 | 人为制造单盘读取失败，界面显示 `--`，其余磁盘正常，程序不崩溃。 |
| AC-06 | 长稳 | 连续运行 8 小时，内存增长 < 10 MB，无崩溃。 |
| AC-07 | 退出干净 | 退出后无残留进程、托盘图标消失、热键释放。 |
| AC-08 | 配置生效 | 修改阈值/透明度/刷新间隔并重启，设置保持。 |

## 9. 待确认事项（不阻塞开发）

1. 横条是**铺满屏幕宽度**还是**内容自适应居中**？默认：内容自适应居中。
2. 是否需要同时显示读写速度（MB/s）？默认：v1 不做，预留位置。
3. 温度单位是否只用摄氏度？默认：是。
4. 是否需要"仅游戏中显示"（检测到全屏程序才出现）？默认：v1 不做，手动热键隐藏。
