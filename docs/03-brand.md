## 1. 名称

**盘温**，取“硬盘温度”之意。

- 两个字，读起来像产品名而不是功能描述；
- 与“温控”“监控”这类泛词区分开；
- 口语可扩展为“盘温条”“盘温怎么样”，不需要解释。

英文/内部标识继续使用 `SsdTempHud`，避免改动已有的构建脚本、互斥体和配置路径。

## 2. 图标概念

```
┌─────────────────┐
│  ████████████   │  ← 青色 HUD 横条（代表顶部悬浮条）
│                 │
│       ██        │  ← 白色温度计
│       ██        │
│      ████       │  ← 橙色水银 + 红色球泡（代表温度）
└─────────────────┘
```

- **深色圆角方块**：和横条本身的深色半透明风格一致。
- **顶部青色横条**：直接对应产品形态——贴在屏幕顶部的悬浮条。
- **温度计**：温度监测的通用符号，16 px 下仍能辨认。
- 水银使用橙→红渐变，球泡用红色：既表达“温度”，也呼应高温警戒色。

## 4. 尺寸与使用位置

| 位置 | 说明 |
|---|---|
| exe 文件图标 | 通过 `csc /win32icon:app.ico` 嵌入 |
| 托盘图标 | 运行时从 exe 提取（`Icon.ExtractAssociatedIcon`），自动适配 DPI |
| 设置窗口 | 标题栏与任务栏图标 |
| 文件属性 | 产品名「盘温」、描述「SSD 温度悬浮监控」、版本 0.2.0.0 |

ICO 内含 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 九个尺寸，使用 PNG 压缩帧。

## 5. 重新生成

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -File tools\make-icon.ps1
```

脚本会同时重写 `app.ico` 和 `docs/icon-preview.png`。修改配色或造型后重新执行 `build.cmd` 即可。
